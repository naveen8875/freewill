# Freewill roadmap

Freewill is developed in measured slices. The next feature is less important than keeping the world deterministic, inspectable, and runnable on ordinary hardware.

## Shipped in the alpha baseline

- Generated finite worlds with 3–100 empty-handed villagers.
- Deterministic physical survival, resources, construction, agriculture, spoilage, weather, injury, collapse, rescue, and death.
- Social actions, relationships, households, voluntary groups, voting, projects, economy, politics, factions, and rebellion as possible outcomes.
- Local deterministic and CPU-only evolving-brain decision modes.
- Multi-seed neuroevolution experiments with saved lineages and held-out validation.
- Evolution observatory, decision inspection, world replay, persistence, and Creator Studio.
- Complete local Docker stack with PostgreSQL and a database dashboard.

## Next

### Public research workflow

- Export a completed experiment as a shareable static report.
- Publish one versioned reference experiment and a small example replay.
- Add confidence intervals and paired-seed comparisons to held-out reports.
- Make environment and reward-version incompatibilities impossible to overlook.

### Better evolving brains

- Establish a repeatable three-generation v7 integrity baseline.
- Add behavioral diversity and novelty metrics without prescribing a society.
- Compare mutation strategies and population selection under the same seed set.
- Add reinforcement-learning experiments only after the evolutionary baseline is reproducible.

### Better worlds and observation

- Expand data-driven resources, recipes, tools, diseases, and structures.
- Improve long-run ecosystem renewal and scarcity dynamics.
- Add clearer spatial, relationship, and institution debugging views.
- Improve replay exports and offline Creator Studio rendering.

### Runtime scale

- Profile 50- and 100-villager worlds on multiple ordinary laptops.
- Move simulation work to a worker only when measured frame stalls justify it.
- Add bounded experiment concurrency and resource controls for shared hosts.

## Not promised

- Conscious or sentient agents.
- A scientifically accurate model of human society.
- A guaranteed path toward civilization, capitalism, democracy, or any other outcome.
- An MMO or anonymous public multi-user service in the current architecture.
- Distributed model training in the first research phases.

Ideas and experiment reports are welcome through GitHub issues.
