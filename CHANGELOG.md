# Changelog

All notable public changes to Freewill are documented here.

## 0.1.0-alpha — 2026-10-25

- Released the first public alpha of the local AI society simulation.
- Added generated finite worlds, survival systems, agriculture, construction, social behavior, projects, institutions, and replayable decisions.
- Added CPU-only evolving brains with saved genomes, mutation lineage, multi-seed evaluation, held-out validation, and lifetime memory.
- Added the evolution observatory for watching episodes, inspecting decisions, comparing generations, and replaying checkpoints.
- Added world persistence, append-only history, PostgreSQL storage, a database dashboard, and a complete Docker Compose stack.
- Added the deterministic Local lab mode for reproducible debugging and offline comparisons.
- Added public documentation, contribution guidance, security policy, release verification, CI, and browser tests.
